## 实际输入材料与教学约束

原材料为本机私有课程资料，公开包只提供以下原创摘要及[来源说明](sources.md)，不附原教案、教材或课件媒体副本。复用此例时可按这些约束开展纸笔教学；需要原课件图像时使用教师自己的课件。

- 本课承接霍尔效应、电势和线性／开关器件，进入电流、位置、转速应用。
- 原知识目标：说明三类被测量的转换关系；解释每转脉冲数与转速关系；列举典型误差及改善方法。
- 原能力目标：计算转速；设计车轮转速检测布置与核验方案。
- 原价值目标包括测量责任、科学素养、合作意识和系统分析。
- 学生能读简单脉冲，但可能混淆频率与转速、遗漏每转有效事件数，并把无脉冲直接解释为静止。

原课中安排依次为：

| 时间 | 原任务 |
| --- | --- |
| 0—3分钟 | 两枚同极磁体圆盘导入，建立每转计数问题 |
| 3—7分钟 | 磁场来源、霍尔输出到计数的支架 |
| 7—12分钟 | 个人转速计算 |
| 12—16分钟 | 小组布置、气隙和计数规则核对 |
| 16—19分钟 | 归纳测量框架 |
| 19—23分钟 | 对照磁场、电流、位置检测的转换条件 |
| 23—29分钟 | 车轮转速检测方案迁移 |
| 29—33分钟 | 漏脉冲情况下的个人计算与解释 |
| 33—37分钟 | 无脉冲的多种解释与核验 |
| 37—41分钟 | 误差怎样进入有效事件判定 |
| 41—44分钟 | 依据缺项修订框架 |
| 44—45分钟 | 总结与布置课后任务 |

课件相关位置：第44、54页为转速／计数；第56页为接近开关限位；第57—58页为霍尔位置反馈与无刷电机；第59—64页为电磁弹射背景、示意及教学装置；第68页列误差与补偿主题。原页的描述范围、图片查看及视频未读情况见来源说明。
