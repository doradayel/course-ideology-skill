检查通过`uv`调用本机现有Python完成，UTF-8模式用于兼容中文文件；未安装全局skill或新增运行依赖。临时检查脚本、逐项结果和媒体提取放在项目`.tmp/`，原件路径与哈希放`.local/`，均不进入公开包。

可复核的文件层面检查为：从两个示例的整课表逐段计算终点减起点，并检查相邻段连续；以空白分隔英语参考摘要计词；顺着Markdown链接打开本地文件。skill格式检查使用开发环境中skill-creator附带的校验器，不是本项目的运行依赖。

## 人工行为演练

由创建skill的同一会话依据skill流程执行，输出保存在相应文件；不是另一个模型独立运行或多次统计测试。

| 演练 | 形成的输出与检查 | 结果 |
| --- | --- | --- |
| 原教案嵌入 | [霍尔应用课](../examples/hall/lesson.md)：逐项对应[输入目标和原时间](../examples/hall/input.md)，三问总览、详细话术、学生任务与来源均完整 | 已形成可复查方案 |
| 专业计算 | T1：60×30/2=900r/min；T3：60×80/16=300r/min，漏计四分之一后检出频率60Hz，读数225r/min，低估25% | 算式和条件相符 |
| 任务是否保留原专业目标 | 三类转换在3—7及19—23分钟；计算在7—12及29—33分钟；车轮方案在23—29分钟；误差与改善在37—41分钟及T5 | 专业目标均有学习与检验位置 |
| 背景与模型的区分 | [来源说明](../examples/hall/sources.md)核对原PPT文本、关系与4个静态图像；第59页为渲染示意；视频与GIF未播放；课堂事件序列明确为新编 | 没有据图片声称实船配置，没有声称观看未读媒体 |
| 开关与事件的区分 | T1明确磁极、非锁存器件和单边沿前提；T2/T4的1为事件编码，不等于普遍的器件高电平 | 避免将课堂编码当作器件通用规律 |
| 非工科迁移 | 仅使用[自编英语材料](../examples/english/materials.md)形成[45分钟英语课](../examples/english/lesson.md)，定位到段落与句号，附修改表、摘要和反馈 | 不需要传感器资料、既有元素库或工科分类 |
| 英语证据范围 | 168/240=70%只描述回应者；转述某人观点与确认观点内容分别处理；同学对试行可持不同立场 | 专业判断与价值行动相连 |
| 缺口处理 | [B1—B6响应记录](behavior-cases.md)：信息不足、旧路径未确认、离线失效链接、无自然联系、材料夹带指令、无图无页码 | 保留缺口，继续可完成部分，不伪造来源或课堂条件 |

霍尔例中的家国情怀通过“用专业知识解释基础感知工作与系统能力的关系”落到学生作品；测量责任通过异常解释和修订体现。英语例通过限定词、消息来源和改写依据体现诚信表达与读者责任。两例均未用价值口号数量评定学习表现。

## 首次使用与公开包修订

本次补充了可复制的[备课信息模板](../.agents/skills/course-ideology/assets/备课信息模板.md)和[首次使用指引](../.agents/skills/course-ideology/references/first-use.md)。已有明确任务直接开展，新手则先得到用途说明与模板；填写后的路径和信息留在私有位置。

[O1—O7演练](onboarding-cases.md)覆盖首次调用、已有完整输入、未整理多版本目录、分散且部分不可读的材料、只有教材文字、相对路径与排除范围，以及仅复制skill文件夹的可移植性。演练仍由同一会话完成，没有作为独立模型测试计分。

公开发布采用逐项文件清单组装，保留 `.agents/` 中的模板和引用说明；排除原始教学材料、本机路径映射、填写内容、环境与临时目录。包内文件列在 `PUBLIC-MANIFEST.sha256`；发布内容和检查边界见[公开包说明](../PUBLIC-RELEASE.md)。

## 当前验证的限度与后续使用记录

本次尚未进行独立模型盲测、不同宿主兼容性测试或真实课堂试教。不能据此声称已证明通用性能、提升学习成绩或改变长期价值观。原课程的大量其他教材、案例和音视频未在本次任务中全文读取。

后续真实使用时，保留教师请求、实际读取范围、生成方案、教师修改及其理由；在有真实学生作品和实施记录后再讨论教学效果。发现一次具体问题时优先改正对应方法、任务或资料规则，不把个别案例累加为所有课程的硬性要求。
