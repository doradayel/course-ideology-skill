# 课程思政备课 Skill

从课程资料出发，帮助教师回答 **融什么、怎么融、融到哪**，形成一课时可直接修改使用的方案。

它把专业内容、价值问题和课堂行动连接起来：教师能看清为什么这样融、放在哪一步、具体怎样讲，学生需要作出什么判断、留下什么作品。适用于各学科，默认优先嵌入原教学。

## 第一次用：照这三步开始

**第一步：让AI读取skill。** 将解压后的 `course-ideology-skill` 文件夹作为AI助手的项目打开。工具支持项目级skill时，发送：

```text
请用 $course-ideology。我第一次使用，请给我简短指引和备课信息填写模板。
```

如果工具未识别这个名称，发送下面这句手动入口：

```text
请读取当前项目的 .agents/skills/course-ideology/SKILL.md，按其中指引开始。我第一次使用，请先给我备课信息模板。
```

**第二步：填写本次课的信息。** 打开[备课信息模板](.agents/skills/course-ideology/assets/备课信息模板.md)，把教师填写区复制到聊天，填入课题、授课对象、时长和现有资料位置。不清楚的留空或写“不清楚”；没有的写“暂无”。也可以复制成项目内的 `.local/备课信息.md` 再填写，并把这个文件位置告诉AI。

**第三步：发送填写内容和资料。** 资料可以填文件夹、单个文件路径、已上传附件名、直接粘贴的文字或网页链接。AI先看已有内容，只补问会影响本次设计的关键信息，再生成方案。你不用先选思政元素，也不用先建库。

已经有明确课题与资料时，可直接提出任务，不必先触发首次引导或完整填表。

## 资料不齐、文件很乱，也可以开始

| 你现在的情况 | AI怎样处理 |
| --- | --- |
| 只有一份PPT，没有教案 | 从课件提炼本课内容，结合对象和时长设计，注明哪些目标与流程是本次拟定 |
| 只有教材、讲义或文字 | 按小节、段落与知识点定位，不编造课件页码 |
| 一大堆文件，尚未整理 | 先看目录，定位这次要讲的内容，再读相关文件，不要求先统一命名 |
| 教案、课件、案例分在不同位置 | 按你填写的路径分别读取，建立本次来源清单 |
| 部分文件打不开或只有扫描件 | 先用可读部分，说明缺口；需要时提示补附件、文字或可读版本 |
| 暂时只有课题 | 先给明确标注假设的方向或草案，不声称已经读过教材 |

每次按实际材料选择工作方式，不要求同时拥有大纲、教材、教案、课件、案例库。

## AI的执行流程

理解本次需求 → 识别与读取相关材料 → 挖掘有专业依据的价值问题 → 定位融入环节并设计讲法 → 核对时间与来源 → 交付可修改方案。

默认成果包括三问总览、整课时间表、详细话术与追问、学生任务和参考要点、来源及实际阅读范围。只需要一个片段或元素分析时按你的要求缩减。

## 在项目内使用

skill 位于 [`.agents/skills/course-ideology/SKILL.md`](.agents/skills/course-ideology/SKILL.md)。使用能读取并执行 skill 指令的 AI 助手，把本仓库作为项目打开；宿主支持项目级 skill 发现时，可通过 `$course-ideology` 调用。

已有其他课程项目时，只复制整个 `course-ideology` 文件夹到该项目的 `.agents/skills/`，保留 `references/`、`assets/` 和 `agents/`。无需全局安装；不同宿主的发现方式以其实际支持为准。若宿主没有自动发现，可直接请它读取该 `SKILL.md` 并按其中方法执行。

这个项目提供可执行的备课指令与示例，由宿主 AI 完成分析，不内置独立聊天服务或模型 API。处理文件及联网的能力来自宿主；纯文本输入不需要安装运行时或数据库。

### 调用示例

**已有教案与课件：**

```text
请用 $course-ideology。
课程：传感器原理及应用；对象：本科三年级；本课45分钟。
资料在 materials/霍尔应用/，优先读第13课教案和课件第59—64页。
用航母电磁弹射案例说明位置检测，嵌入原教学。
请回答融什么、怎么融、融到哪，给出话术、任务、参考要点和时间调整。
```

**资料很多：**

```text
请用 $course-ideology。课程资料在 materials/课程资料/。
先看目录和大纲，只读取与“异常数据处理”这一课相关的内容。
对象是大二学生，45分钟，已有教案请优先保留专业主线。
需要外部事实时可以检索；请注明实际阅读范围。
```

**只有文字材料：**

```text
请用 $course-ideology。下面是大学英语阅读材料和本课目标。
为45分钟的事实与观点辨析课设计融入，重点是准确转述与依据意识。
没有原教案，请给出完整流程、可以直接使用的任务和参考答案。
```

也可以只请求某页的元素分析、一个融入片段，或检查现有设计哪里牵强，不必每次生成整课。

## 资料与结果放哪里

| 位置 | 用途 | 默认分享范围 |
| --- | --- | --- |
| `.agents/skills/course-ideology/` | 通用入口、教学方法、来源规则、输出约定 | 可随项目分享 |
| `.agents/skills/course-ideology/assets/备课信息模板.md` | 原始空白模板，供复制填写 | 可随项目分享 |
| `examples/` | 原创教学整理与必要出处 | 本项目公开示例 |
| `verification/` | 测试任务、行为记录、检查结果 | 可随项目分享 |
| `materials/` | 教师自己的原始课程资料 | 已忽略 |
| `outputs/` | 本机新生成的备课方案 | 已忽略，可按需另行整理公开稿 |
| `.local/` | 填写后的备课信息、本机资料路径与来源映射 | 已忽略 |
| `.tmp/` | 转换缓存、截图、临时测试 | 已忽略 |
| `dist/` | 本机生成的发布ZIP | 已忽略，不把压缩包再次打进自身 |

PDF、扫描件、PPT、DOCX和音视频按宿主能力读取。已有提取文本可先用，关键图片、页码及数据按需回看原件；有 `any2md.ps1` 的 Windows 环境可按需转换，其他环境使用等效工具。查看[资料处理规则](.agents/skills/course-ideology/references/materials.md)。

## 设计原则与当前边界

思政联系从本课专业问题推导，分类随课程调整；已有元素库可辅助，使用者不必先建库。来源事实、教学引申和新编情境分别说明，未读视频和失效来源保留缺口。没有合适联系时允许明确说明。

示例属于备课设计，尚未提供课堂实施成效证据。本机验证也不能证明所有课程、模型和宿主都表现相同。改进时保留真实使用中的问题与修改依据，避免只增加规则。

本项目未包含原教材、原课件及其中图片视频的再分发副本。示例中的网页和课件引用用于回查，第三方素材的权利仍归原权利人。公开包内容与排除范围见[发布说明](PUBLIC-RELEASE.md)；解压后上传其中的仓库内容时，保留 `.agents/` 目录。仓库许可证尚未指定。
