# 首次使用指引

## 什么时候提供指引

老师明确表示第一次使用、不知道怎么开始，或调用skill但没有具体任务时，先简短说明用途，提供填写模板。已有明确课题、对象、时长和可用资料时直接开始；信息可以来自聊天、附件或资料，不强求填模板。

使用下面的开场，可根据已知信息缩短：

> 我可以根据你的教学材料，帮助你回答“融什么、怎么融、融到哪”，给出课堂话术、学生任务和具体插入位置。你只需说明这次讲什么、教谁、讲多久，以及资料在哪里；不用先选思政元素，也不用先建素材库。
>
> 请复制下面的模板填写，不清楚的项留空。资料可以是文件夹、单个文件、已上传附件、直接粘贴的文字或网页链接；有哪种就填哪种。我会先看已有内容，只补问会影响本次设计的关键信息。

随后把 [备课信息模板](../assets/备课信息模板.md) 的教师填写部分完整呈现为可复制文本，或在能显示文件的环境中同时提供可打开的模板。不要只给一个老师无法访问的内部引用路径。填写帮助可压缩为一句，避免把全部内部方法和规则发给老师。

## 读完填写内容后怎样继续

先用一两句话确认本次范围和准备读取的资料，再开始读取，不把确认写成等待批准的步骤。例如：“这次按大一学生、45分钟，先读你指定的第三章讲义；没有原教案，我会根据讲义组织流程，并说明目标假设。”

课程、课题、授课对象或时长中缺少会明显改变设计的信息时集中补问；能从文件确定的先读文件。只填资料总目录时先浏览目录，能定位目标课时就继续；若老师连课题也未指定，从目录列少量有明确名称的候选供选择，暂不擅自处理整门课程。

模板中的空白、填写提示和示例不当作真实资料位置或已授权任务。老师写“没有／暂无／不清楚”时接受这一状态，说明下一步能做什么，不反复要求补齐全部资料。已经填写的内容不要求再口述一遍。

## 路径与使用环境

相对路径按老师声明的基准目录解析；没有声明时按当前课程项目目录解析。老师提供目录外的具体文件时，在宿主允许访问的范围内读取。路径不存在或没有权限时，指出是哪一项无法读取，继续使用其余资料，并提示可重新给路径、上传附件或粘贴相关片段；不为寻找文件扫描整块磁盘。

仅有聊天附件时按附件名称引用；没有文件系统时可直接用聊天中的填写内容，不要求创建目录。具备写文件能力且老师希望保存时，将填写内容留在项目 `.local/`，新备课结果默认放项目 `outputs/`；发布包只保留空白模板和明确整理的示例。

老师使用的工具未发现该skill时，提供一种简单的手动入口：请AI读取该skill文件夹里的 `SKILL.md` 并按需读取相邻引用文件。若工具本身无法访问资料，明确读取缺口，不让安装步骤代替备课任务。
