# 资料读取与来源

## 按实际资料组合选择入口

老师可以提供目录、具体文件、附件、文字和链接的任意组合，不要求固定目录结构或文件类型。明确指定的本课材料优先；总目录只用于补充定位，排除老师指定不读的资料。

| 实际材料 | 工作方式 |
| --- | --- |
| 有原教案和相关材料 | 先读原流程与专业目标，再对照本课材料，按原教学嵌入并说明时间调整 |
| 只有课件或讲义 | 从本课内容提炼知识与能力目标，结合已知对象和时长设计；没有原流程时标明为新建安排 |
| 只有教材或章节文字 | 以小节和知识点定位，按本次课题组织；不编造课件页码，也不默认整章都能在一课时讲完 |
| 有大目录但未整理 | 先看文件名、子目录和大小，按课题寻找相关版本；章节编号不同不强行配对 |
| 资料分布在多个位置或格式混合 | 按用途建立本次来源清单，串起课题与知识点；能读的部分先用，转换只针对实际需要的文件 |
| 只有图片、扫描件或音视频 | 按宿主能力识别与转写相关部分；关键内容读不清时保留缺口，可先形成片段框架 |
| 只有文字、案例描述或网页 | 直接按段落、附件名或链接处理，不要求本地目录或现成元素库 |
| 暂无材料 | 课题清楚时先提供标明假设的设计方向或草案；关键事实、页码和原目标不作已读结论 |

发现多个可能版本时结合教师指定、文件内容和版本信息判断，不单凭修改时间选“最新版”。若差异影响本课目标或引用，展示具体候选并集中询问；其余不影响判断的细节保留各自出处。

路径不存在、附件不可访问、转换工具缺失或某种格式无法读取时，说明受影响部分，继续利用其他材料；需要时提示上传、粘贴或更换可读版本。相对路径按明确基准或当前项目解析，不为补齐模板扫描未指定位置。

## 逐步扩大读取范围

先浏览用户指定目录的结构、文件名和大小，找课程大纲、目标课时教案、相应课件和教材小节。先读取文字与现成提取稿，发现与教学判断有关的缺口后再回到原件；不要为了完整感先转换全部教材、视频或历史版本。

对大纲取课程定位、对象、目标、学时和章节关系；对本课教案读完整流程；对课件按相关原页读取，并补读建立专业关系必需的前后页。相关知识点跨页时扩大到能说明问题的完整范围。在输出中交代实际读了什么、未读什么。

已有案例库、元素库和知识点索引可缩小检索范围。读命中条目的完整专业切入、教学联系及来源，再判断本课是否适合。保留原编号以便回找，不把已有编号当作事实核实或课堂有效的证明；本次新建议不冒用原编号。一次备课不自动写回教师的库。

## 按宿主能力读文件

| 输入 | 处理与边界 |
| --- | --- |
| Markdown、文本、JSONL | 搜索定位后读相关完整段落或记录；记录原小节、稳定编号或行范围 |
| PPTX | 原幻灯片序号为主；文本、图片、备注、动画及嵌入视频分别处理。文本提取或单帧图片不能证明已看完动画、视频 |
| PDF、扫描件 | 用可用阅读或 OCR 工具，区分 PDF 物理页和印刷页。关键图文回看原页；识别不清的字、公式与数值注明不确定 |
| DOCX | 以标题和段落定位；流式提取未保留版面时不编造页码 |
| 音视频 | 按任务所需片段转写或观看，记录实际时间段；仅取得链接或缩略图时如实说明 |
| 网页 | 实际打开正文后引用题名、发布方、日期及直达链接，记录本次访问日期 |

优先用宿主已有能力。有 `any2md.ps1` 的 Windows 环境可按需调用，输出到项目内，例如：

```powershell
any2md.ps1 "materials/目标课件.pptx" ".tmp/converted/目标课件"
```

先确认当前版本的参数及输出方式，避免覆盖原件。其他环境可使用等效转换工具，或直接接收教师已提取的文字。该 skill 不绑定转换服务、特定操作系统、模型厂商或向量数据库。工具缺失时说明能完成的范围；依赖缺失不等同于资料已经读取。

## 形成可回查的依据

给本次实际使用的资料分配简短来源号，例如 S1、S2。来源表至少说明题名或文件名、实际位置、用途及阅读方式；多个文件的“第59页”不能混用。技术参数、人物、事件和直接引语紧邻具体来源；课堂任务可以整段标注“本次新编”。

区分以下性质，允许同一设计同时用到几种依据：

- **专业事实：** 来源支持的概念、过程、历史事件或参数，保留成立条件。
- **材料明确价值表达：** 来源本身明确表达的价值或规范；准确概述或有限引用。
- **教学引申：** 教师基于专业问题提出的价值联系，说明中间的判断，不冒充作者原意。
- **新编情境：** 本次编写的故事、数据、任务、预期学生回答或教师话术，明确用于教学。预期回答不代表真实学生已这样回答。

专业教学建议不需要逐句贴标签；在任务开始、片段说明和来源表中清楚标明即可。源文件提到一个工程、拍到某个部件或公开了技术方案，不能据此断言特定实际装备采用该方案。

旧来源路径失效时，在用户给定范围内找候选，结合文件内容、页标题、原摘录和版本信息确认对应关系。只凭同名或相同页码不能确认。保留“旧引用—当前材料—匹配依据”的本地记录；未确认时引用当前确实读到的内容并说明定位缺口，不悄悄改写旧库。

## 按需补外部事实

先使用足够支撑本课的已有资料；事实缺口确实影响教学时再检索。事件背景优先原发布单位和权威公开报道，技术内容优先原论文、教材、标准发布方或厂商技术文档。关注时间、版本、适用条件和原文是否支持具体说法。

网页打不开时只可把链接列为未读线索，不能用搜索摘要冒充已读正文。可以改找支持同一事实的可靠来源，或删去非必需事实。离线时仍可用现有专业材料提出明确标注的教学引申和假设情境；没有证据的事实保持未知。

## 本机资料与公开示例

原课件、教材、学生资料和课程库默认只读。临时转换、截图和测试文件放项目 `.tmp/`；本机路径、私有来源映射放 `.local/`；两者加入项目忽略规则。用户指定的正式备课成果可放 `outputs/`，需要公开的原创示例单独整理到 `examples/`。

公开包使用相对路径、资料名称及原页码，清除个人信息、机器绝对路径、内部平台凭据和未获授权的原件。仅保存必要引用和原创教学整理；来源链接不代表拥有素材再分发权。是否实际发布由用户的发布任务决定。
