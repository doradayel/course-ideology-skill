# 备课信息模板

复制下面“教师填写区”到聊天，或另存为项目内的 `.local/备课信息.md` 再填写。**不需要每项填满；不清楚的写“不清楚”，没有的写“暂无”。** 不必填写姓名、联系方式、账号、学生名单等个人信息。

资料不必整理成固定目录，也不要求同时有大纲、课件和教案。文件夹、单个文件、已上传附件、直接文字和网页链接都可以；相对路径按当前项目目录理解，也可以自行说明基准目录。

## 教师填写区

```text
请使用 course-ideology，帮我完成这次课程思政备课。

【基本信息】
课程名称：
本次课题／章节／知识点：
授课对象（学段、年级、专业或已有基础）：
本次课中时长（分钟；只设计片段也可说明）：
希望得到什么（完整一课时方案／一个融入片段／元素分析／优化现有设计；不填则按一课时方案）：

【教学资料：有哪项填哪项，至少说明现有材料或“暂无材料”】
资料总目录（可选，文件较多时填）：
优先读取的文件、附件或链接（可多行）：
本次对应页码／小节／视频片段（知道才填）：
相对路径的基准目录（不填则为当前项目目录）：
不需要读取的目录、文件或历史版本（可选）：

【补充要求：可全部留空】
已有教学目标（或写“请从资料提取”）：
原教案／教学流程的位置（没有则写“暂无”）：
想采用的案例／已有思政目标（没有则由AI分析）：
必须保留的专业内容、活动或考试要求：
课堂条件（如只能纸笔、有实验设备、可分组等）：
是否允许按需联网补充（不填则按需检索权威来源；可写“不联网”）：
结果保存位置（不填则优先在聊天交付；需要文件时保存到项目outputs目录）：
其他要求：
```

## 资料填写举例

以下只是填写方式，请替换成自己的内容，不要把示例当成真实文件。

| 你手上有什么 | 如何填写 |
| --- | --- |
| 一整个课程文件夹 | 资料总目录填 `materials/课程资料/`，再写清本次课题；无需先重命名全部文件 |
| 只有一份课件 | 优先读取填 `materials/本课课件.pptx`，知道对应页就补页码；没有教案也可开始 |
| 教材、教案、课件分开放 | 在优先读取处逐行列出各自路径并注明用途，不要求放到同一个目录 |
| 只有上传附件 | 写“已上传：本课讲义.pdf”，以及希望处理的小节 |
| 只有文字或网址 | 写“以下粘贴本课内容”并附文字，或填写可以访问的网页链接 |
| 暂时只有课题 | 明确写“暂无材料”；AI先给设计方向和待补条件，不会声称读过教材或标出不存在的页码 |

填完后直接发送，AI会先确定读取范围，利用已有材料继续工作；它不会要求你先建思政库或把所有选填项补齐。
